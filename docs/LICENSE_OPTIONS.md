# License decision required

A software license must be selected before public GitHub/Zenodo release. Common choices:

- **MIT**: simple permissive reuse with attribution and warranty disclaimer.
- **BSD-3-Clause**: permissive, with a non-endorsement clause.
- **Apache-2.0**: permissive and includes an explicit patent grant.
- **GPL-3.0**: requires redistributed derivative software to remain under GPL.

This release candidate intentionally does not make that legal choice on the author's behalf. After selection, add a root `LICENSE` file and update `CITATION.cff`, `.zenodo.json`, and repository metadata.
